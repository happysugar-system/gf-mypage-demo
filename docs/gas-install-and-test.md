## 導入（既存ファイルを変更しない）
1. 対象スプレッドシート https://docs.google.com/spreadsheets/d/17IzIUJeYQw3nO8GZsUSCgLfHVECNINZNkQdg38GW57o/edit?gid=791687336 を開く。
2. 「拡張機能」→「Apps Script」を開く。既存プロジェクトのバックアップを取る。
3. 左側の「＋」→「スクリプト」で新しいファイルを作り、`GF_連絡先同期_安全テスト` と名付ける。
4. `gas/GF_連絡先同期_安全テスト.gs` の全文をコピーして貼り付け、保存。
5. 関数一覧で `GF_連絡先同期_読取専用テスト` を選び「実行」。初回の権限確認を行う。
6. 実行ログに `構成OK / データ行数: ...` と `読取専用診断完了。本番の連絡先は変更していません。` が表示されるか確認する。
7. エラーが出た場合はログの**エラーメッセージと行番号のみ**共有。氏名・電話番号・メールアドレスは共有しない。
